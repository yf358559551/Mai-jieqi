# 风味标签规则

标签描述餐品的**风味与形态**，只依据本次 MCP 返回的名称、分类、规格和营养数据来打，看不出来就不打。节气和体感的权重都作用在这些标签上（见 `data/solar_terms.json`）。

| 标签 | 何时打 | 依据 |
|---|---|---|
| 热饮 | 名称或规格明确为热（热拿铁、热朱古力、热豆浆、热茶等） | 品名/规格 |
| 冰饮 | 冷饮、碳酸饮料、冰咖啡、果汁冰饮 | 品名/分类 |
| 冰品 | 甜筒、圣代、麦旋风等冰淇淋类 | 分类 |
| 热食 | 现做的主食或热点心：汉堡、卷、粥、派、早餐蛋堡等 | 分类 |
| 汤粥 | 粥、汤类 | 品名 |
| 谷物 | 含面包、饼、粥等主食部分 | 分类 |
| 油炸 | 薯条、炸鸡、鸡块、炸鸡类汉堡等 | 品名 |
| 清爽 | 玉米杯、沙拉、蔬果类配餐、无糖饮品 | 品名 |
| 甜 | 派、甜品、含糖饮品 | 品名/分类 |
| 果味 | 果味派、果汁、果味饮品 | 品名 |
| 奶香 | 奶茶、拿铁、牛奶 | 品名 |
| 咖啡 | 咖啡类 | 分类 |
| 辣 | 品名带辣/香辣/麻辣 | 品名 |
| 时令限定 | `campaign-calendar` 或菜单标签明确为限定/新品，且当前有效 | 活动/标签 |

- **蛋白**：不手打。脚本在整份候选蛋白质合计 ≥ 20 g 时自动加上；营养数据缺失则不加。
- 同一组件可打多个标签，例如热苹果派 = 热食 + 甜 + 果味。
- 冷热无法确认的饮品（只写“咖啡”）不打热饮/冰饮，可在推荐时问一句“要热的还是冰的”。
- 忌口标签（如“辣”“咖啡”）由用户提出，脚本会硬性排除；过敏原不能靠标签判断，需提醒用户以门店信息为准。
